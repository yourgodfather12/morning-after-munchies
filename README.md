# Morning-After Munchies 🍳🥓🧇

**What breakfast cures last night’s regrets?**  

A fun, cheeky web app that asks about your hangover level, cravings, and hunger, then serves up a dynamically generated breakfast suggestion—complete with emojis, funny names, and “morning-after stats.” Built with **Hashbrown** for interactive, animated UI cards. Perfect for those rough post-hookup mornings. 😵😴😎

---

## 🎯 Features

- **Mood Questions:** Answer 3 quick questions about last night:
  - Hangover level 😵 / 😴 / 😎
  - Sweet, savory, or questionable cravings
  - Hunger intensity
- **Dynamic Breakfast Suggestions:** Automatically generates a breakfast based on your answers.
- **Cheeky Names & Emojis:** Breakfasts like *Heartbreaker Hash*, *One-Night Waffle*, or *Pickle & Chocolate Smoothie*.
- **Morning-After Stats:** Optional fun stats cards like “Regret Level: Medium” or “Coffee Required: 2x”.
- **Animated Cards:** Hashbrown-powered interactive UI makes results pop visually.
- **Shareable:** Copy your breakfast results for social fun.
